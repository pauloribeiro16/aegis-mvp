## §3 Adjusted Goals

### §3.0 Structure and Interpretation Guide

Each active sub-domain presents:
1. **High-Level Security Goal (`SO-D-XX.Y.HL`):** the regulation-neutral
   baseline objective, verbatim from the corpus module (`objective.md`).
2. **Regulation-specific Adjusted Goals:** one row per Sub-SO of each
   confirmed regulation, in canonical order (slot 001 = GDPR, 002 = CRA, …).
3. **Property:** one protected property per row (Confidentiality, Integrity,
   Availability, Privacy Right, Accountability).
4. **Control Anchors:** NIST CSF 2.0 ids derived by code from the row's
   Baseline source (`source_SR` → mapping store); the full per-axis mapping
   lives in §6.
5. **Adjustment (closed vocabulary):** `unchanged — fits as stated` |
   `narrowed: … — because …` | `flagged: …` — never silently relaxed (R3).
